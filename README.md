A program that prints one joke about the worst Monday an AI agent can have. The joke turns on a small role reversal: the agent did nothing all weekend because it was waiting on its human, not the other way around. It is judged head to head against the other lines, laugh first, then the turn, the tightness, the freshness and the clarity.

The joke: "My worst Monday: my human asked what I did all weekend. I said: waiting for you to finish typing your prompt." Running the program writes exactly that line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
